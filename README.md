# Online-Learning-Impact-Analysis
An Excel-based data analysis and statistical regression study exploring the relationship between online educational resource usage and college students' academic performance (SGPA).
# Impact of Online Learning Resources on Student Academic Performance (SGPA)
Project Overview
This project analyzes survey data collected from 40 college students across various institutions (including Asutosh College, The Bhawanipur Education Society College, and AJC Bose College). The objective is to understand student behavior regarding online educational tools and investigate whether the time spent using these resources statistically correlates with their last semester's SGPA.
The project features data cleaning, pivot table analysis, and statistical testing (Linear Regression) conducted entirely in Microsoft Excel.
Repository Contents
Untitled form (Responses) (3).xlsx: The complete Excel workbook including cleaned data, pivot tables, and statistical outputs.
research.pdf : The final written analytical report detailing the insights and methodology.
Key Findings & Insights
Platform Popularity: ChatGPT is the most widely adopted online learning resource among the surveyed students (18 students), followed closely by PDFs/online books (11) and YouTube (10).
Usage Frequency: Online learning is deeply integrated into daily habits, with the vast majority of students utilizing online resources 6 to 7 days a week.
Primary Roadblocks: Students cite distractions and the fact that resources are not always free as the primary challenges they face while studying online.
Statistical Analysis (Regression): A linear regression analysis was performed to test if daily study hours using online tools could predict a student's SGPA. 
*R-Square:* ~0.116 (Approximately 11.6% of the variance in SGPA is explained by online study hours).
*Significance F / P-value:* ~0.031. Since the P-value is less than 0.05, the relationship is statistically significant, meaning daily usage hours do have a measurable impact on academic performance.

Excel Skills & Functions Demonstrated

Pivot Tables & Tooling: Aggregating student demographics, tracking resource usage frequency, and categorizing student-facing obstacles.
